# Security

Skipz runs only on youtube.com and sends nothing about you or your videos off your computer. If you find a way to make it do otherwise, or any other security problem, please tell us privately first.

Report it privately on GitHub: open this repository's Security tab, choose "Report a vulnerability" and describe what you found and how to reproduce it. Only the maintainer sees it. I am one person, and I reply within a few days. I credit you in the release notes if you like.
