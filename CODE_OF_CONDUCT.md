# Code of Conduct

Be kind. Assume the other person is trying to help.

- Disagree with the idea, not the person.
- No harassment, no insults, no slurs, no personal attacks.
- Keep reports and reviews specific and useful.
- Private details about other people stay private.

If someone breaks these rules, a maintainer may edit or remove comments, close threads, or block the account. To report a problem privately, use the "Report a vulnerability" button on this repository's Security tab, or open an issue if it is not private.
